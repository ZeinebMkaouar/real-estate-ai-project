\# Real Estate AI Predictor



Pipeline MLOps end-to-end de prédiction de prix immobiliers (California Housing Dataset).



\## Structure du projet

\- `backend/` — API REST FastAPI servant les prédictions

\- `frontend/` — Interface Next.js pour l'estimation interactive

\- `notebooks/` — Notebook d'entraînement du modèle (EDA, benchmark, sauvegarde)



\## Stack technique

\- \*\*ML\*\* : Scikit-Learn, Pandas, NumPy, Joblib

\- \*\*Backend\*\* : FastAPI, Uvicorn, Pydantic

\- \*\*Frontend\*\* : Next.js, TypeScript, Tailwind CSS
